How to update an image:
1. Click the wiki link above → go to the suit's page
2. Right-click the main suit image → Copy image address
3. Open msstore.html → find the line containing id:'SUITID'
4. At the end of that line, replace img:'...' with the copied URL
5. Mark the row as ✅ DONE in this file
